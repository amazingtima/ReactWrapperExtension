# React Code Wrapper

Wrap your React code with these 10 most-used patterns. Quick actions that save time every day.

## About

VS Code extension with 10 everyday React wrappers. Select code → right-click → **React Wrapper** → pick a pattern.

1. Console Log
2. JSX Container (`div`)
3. JSX Condition (`&&`)
4. JSX Ternary (`? :`)
5. JSX Fragment (`<>...</>`)
6. Try / Catch Block
7. React useEffect
8. Async Handler Wrapper
9. React useState
10. JSX Map (`.map`)

## How to use

1. Select your part of the React code
2. Right-click and select the **React Wrapper** tab
3. Select the required wrapper

You can also use Command Palette (`Ctrl+Shift+P`) and search for `React Wrapper`.

## Install

- [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=Titan91.react-wrapper-extension)
- Or search **React Code Wrapper** in VS Code / Cursor Extensions

## Development

```bash
npm install
npm run compile
```

Press **F5** to open the Extension Development Host and test locally.
